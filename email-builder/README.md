# Abundance Email Builder

Static prototype for assembling Abundance email templates from approved rows.

## Local use

Open `index.html` in a browser, or serve the folder with any static file server.

## Netlify

Use these settings:

- Base directory: `email-builder`
- Build command: leave blank
- Publish directory: `.`

The app has no backend and stores drafts in browser `localStorage`. Use **Save JSON** and **Load JSON** for portable email files, and **Download HTML** or **Copy HTML** for Drip-ready output.
